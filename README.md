# 🏦 Banking Risk Analytics with Python, MySQL, Power BI & Excel

A comprehensive data analytics project combining **Python**, **MySQL**, **Power BI**, and **Excel** to uncover insights and assess risk in the banking sector. This project showcases end-to-end data handling, from data preprocessing to interactive dashboarding.

---

## 📌 Problem Statement

To analyze and visualize **risk analytics in banking**, aiming to reduce financial losses by identifying high-risk clients and improving decision-making in lending processes.

---

## 💡 Solution

- Performed **data cleaning and exploratory data analysis (EDA)** using Python (pandas, seaborn, matplotlib).
- Stored and queried data using **MySQL**.
- Used **Excel** for initial data collection, transformation, and staging.
- Created interactive dashboards in **Power BI** using DAX calculations for deep financial insights.

---

## 📊 Dataset Overview

Data was sourced from Excel and included fields such as:
- Client demographics
- Account details
- Loan and deposit values
- Advisors and banking relationships

It was imported into **MySQL**, cleaned using **Python**, and analyzed across multiple stages.

---

## 🔍 EDA Highlights (Python)

- Used `pandas` for data manipulation
- Plotted trends with `matplotlib` and `seaborn`
- Identified nulls, outliers, and relationships in client behavior
- Feature engineered variables such as:
  - `Income Bands`

---

## ⚙️ DAX Measures in Power BI

- `Total Clients`: Count of distinct clients
- `Total Loan`: Sum of all loan-related columns
- Custom filters on income band, advisor, nationality
